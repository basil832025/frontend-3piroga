# Фронтенд 3piroga

Этот каталог — отдельный Git-репозиторий пакета `frontend-3piroga`, подключённый к общей админке MyAdmin. Для задач 3piroga здесь меняй только его маршруты, провайдер, шаблоны, стили, скрипты и ресурсы. Не переноси проектный фронтенд в общие каталоги админки и не затрагивай другие frontend-пакеты.

Изменения общей админки, модели, сервисов, Filament, схемы БД и сидеры делай в родительском репозитории по его `AGENTS.md`. В этом пакете не создавай миграции и не записывай переводы напрямую в БД. Когда нужны тексты из БД, сначала уточни, создавать ли сидер в админке или после проверки окружения записывать их непосредственно в БД.

Перед тестами и сборкой проверь активный проект и состояние обоих Git-репозиториев. Общий `npm run build` собирает и другие фронтенды; не включай их артефакты в изменение 3piroga. После работы сообщи отдельно о правках этого пакета и родительского репозитория.
